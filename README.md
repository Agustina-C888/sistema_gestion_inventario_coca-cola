# Sistema de Gestión de Inventario - The Coca-Cola Company

## Descripción del sistema
Sistema de gestión de inventario que centraliza el control de materias primas y productos terminados. Registra entradas, salidas y ajustes de stock. 
Facilita el intercambio de información entre Producción, Compras, Distribución y Ventas.

## Historias de usuario
1. Como vendedor: quiero consultar si hay stock de un producto, para no ofrecerle al cliente algo que no tengo.
2. Como encargado de Logística: quiero registrar el ingreso de un lote terminado, para que el stock quede actualizado.
3. Como responsable de Compras: quiero recibir una alerta cuando el stock baja del mínimo, para hacer el pedido de reposición a tiempo.
